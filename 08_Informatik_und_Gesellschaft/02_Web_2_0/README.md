# Web 2.0

## Gyors vizuális kép

| Web 1.0 jelleg | Web 2.0 jelleg |
|---|---|
| inkább statikus oldalak | interaktív, részvételi web |
| inkább olvasás | olvasás + írás + megosztás |
| kevés felhasználói tartalom | sok user-generated content |

## Mi a Web 2.0 lényege?

A Web 2.0 a részvételi web gondolata.

Ez azt jelenti, hogy a felhasználó:

- nem csak fogyasztja a tartalmat
- hanem létrehozza, módosítja, megosztja is

## Milyen példák tartoznak ide?

- közösségi hálózatok
- wikik
- videómegosztók
- fórumok
- értékelések és kommentek

## Miért fontos?

Mert a Web 2.0 nagy változást hozott:

- kommunikációban
- közösségépítésben
- marketingben
- tudásmegosztásban
- online üzleti modellekben

## Milyen előnyei vannak?

- gyors információmegosztás
- közösségi együttműködés
- felhasználói részvétel
- könnyebb publikálás

## Milyen kockázatai vannak?

- álhírek
- adatvédelmi problémák
- online zaklatás
- platformfüggőség
- manipuláció és buborékhatás

## Iskolai wiki mint részvételi rendszer

Egy tananyagoldalt az oktató egyedül is szerkeszthet. Ha a tanulók javításokat és magyarázatokat küldenek, megvitatják a változásokat, majd a közösség áttekinti azokat, megjelenik a részvételi web szemlélete. Ehhez módosítástörténet, világos szerkesztési jogok, moderálás és forrásmegjelölés is kell.

A Web 2.0 történeti és szolgáltatási fogalom. Nem HTTP-verzió, HTML-szabvány vagy kötelező technológiai csomag. Egy korszerű JavaScript-keretrendszer használata önmagában nem jelent közösségi részvételt. A korai weben is léteztek interaktív megoldások, ezért a Web 1.0 és 2.0 táblázata irányzatokat egyszerűsít, nem éles műszaki határt ír le.

A példában a haszon a közösen javított tananyag. A működtetés feladata az ellenőrizhető szerzőség, a kulturált vita és a hibás tartalom követhető javítása.

## Vizsgán jól használható megfogalmazás

> A Web 2.0 a web fejlődésének azt a szakaszát jelöli,
> amelyben a felhasználók már nemcsak fogyasztják,
> hanem létre is hozzák és megosztják a tartalmat.  
> Ide tartoznak például a blogok, wikik, közösségi oldalak és más felhasználói tartalomra épülő platformok.  
> Előnye az együttműködés és a gyors kommunikáció,
> kockázata viszont az adatvédelmi probléma, az álhír és a manipuláció lehet.
